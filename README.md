# Dprj

React + TypeScript + Vite application with an Express backend and Supabase integration.

## Development

```bash
npm install
npm run dev
```

Backend dependencies:

```bash
cd backend
npm install
```

See `.env.example` and `backend/.env.example` for environment configuration.
